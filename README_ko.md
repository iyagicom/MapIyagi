# 맵이야기 (MapIyagi)

**땅을 보는 지도 — 브이월드 3D 지도 위에 지적도·용도지역·일조시간·로드뷰를 한 화면에. 토지 조사, 태양광 부지 찾기용.**

[English](README.md) · [한국어](README_ko.md)

![MapIyagi](mapiyagi.png)

## 왜 맵이야기인가

- **필지를 클릭해 모으면 면적이 바로.** 필지를 누를 때마다 목록에 쌓이고, 지번·지목·면적(㎡)·구역과 **총 면적 + 평수**가 계속 합산됩니다.
- **실제 규제가 보입니다.** 리·동과 지역·지구를 토지이용계획과 같은 기준으로 필지마다 조회합니다. 농림지역이면서 농업진흥구역인 땅이면 실제 규제인 **농업진흥구역**을 보여 줍니다.
- **태양광 부지의 일조시간을 계산.** 선택한 필지의 연평균 하루 일조시간을, 주변 산과 지형이 가리는 것까지 반영해 구합니다 — 태양광 부지분석 도구와 같은 방법입니다.
- **가 보지 않고 봅니다.** 로드뷰를 켜면 지도와 반반으로 나뉘고, 필지 안에 길이 없는 시골 땅도 몇백 미터 떨어진 도로에서 찾아 보여 줍니다.
- **3D 로 지형까지.** 실제 고도가 들어간 3D 지도에서 경사와 산세를 봅니다.

## 기능

### 지도
- 브이월드 3D 지도, 지번·도로명·장소 검색, 최근 검색 100건, 내 위치

### 지적도·필지
- 지번 글씨 / 연속지적 경계선을 따로 켜고 끄기
- 우클릭 → 그 자리의 지번·고도, 시군구부터 리까지 붙은 전체 주소 복사
- 선택 필지 목록: 지번·지목·면적·일조·구역, 총 면적과 평수
- 선택한 필지 묶음을 이름 붙여 저장하고 불러오기

### 용도구역
- 도시·관리·농림·자연환경보전지역, 농업진흥지역, 개발진흥지구를 색으로

### 일조 분석(태양광)
- 태양 위치를 직접 계산하고 필지에서 본 지형 스카이라인을 따져 12개월 평균
- 맑은 날 기준 이론 일조시간(건물·나무 그림자, 날씨는 제외)

### 측정·로드뷰
- 두 점의 수평거리(m)와 경사각(°), 클릭한 지점의 고도
- 위성지도 + 로드뷰 반반 화면, 바라보는 방향 표시, 지도·검색·필지를 따라 이동

## 다운로드

**[⬇ 최신 버전 받기](https://github.com/iyagicom/MapIyagi/releases/latest)**

| 내 시스템 | 받을 파일 |
|---|---|
| 우분투 · 데비안 | `.deb` |
| 그 밖의 리눅스 | `.AppImage`(설치 없이 실행) 또는 `.zip` |

```bash
sudo apt install ./mapiyagi_*_amd64.deb      # 우분투 / 데비안
```

대한민국 지도·지적 자료(브이월드, 국토정보플랫폼)를 씁니다. 인터넷 연결이 필요합니다.
